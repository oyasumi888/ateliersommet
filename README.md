# Atelier Sommet

Marketing site for a software development & technical marketing agency: React + TypeScript + Vite + Tailwind CSS.

```bash
npm install
npm run dev     # http://localhost:5173
npm run build   # type-check + production build
```

See [DOCUMENTATION.md](./DOCUMENTATION.md) for architecture, design tokens, how to edit content, and the pre-launch checklist.
